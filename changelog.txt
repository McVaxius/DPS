Unreleased - 2026-09-29

- Hide the non-default foreground frozen-frame option unless the main-window Advanced options checkbox is selected. Existing mode settings and render behavior are preserved.
- Added a Resolution tab with an explicit choice of XA Slave command IPC or first-party Custom Resolution reflection and an optional toggle binding in the existing hotkey table. XA Slave retains separate scale controls and toggles track successful DPS requests for the session.
- Missing resolution providers can be installed through Dalamud's existing installer. XA Slave's repository is added or enabled only when its install button is clicked; first-party Custom Resolution uses the official repository.
- Embedded Custom Resolution's native Display, Gameplay, and Common settings with its own Save and apply behavior, using the verified V1.Display and V1.Game fields from version 1.1.6.0.
- The first Custom Resolution enable applies the embedded Account 1 preset once and records completion only after saving succeeds. Later enables and provider switches preserve user edits.
- Custom Resolution's DPS toggle now sets gameplay to 1.0x when off while retaining native scaling, then restores the session's chosen gameplay scale when on. A new session starting at 1.0x uses 0.05x on the next enable; display settings stay untouched after the initial preset.

- Added an Advanced button at the top of the main window. Automatic rendering exceptions, recovery timing, and advanced background throttle controls now live in a separate window and save/apply immediately.
- Made every automatic rendering exception opt-in. Configuration schema 13 disables existing recovery enables once during upgrade while preserving timing values and unrelated settings.
- Added individual foreground display-recovery options for no monitors, no current monitor, missing/hidden/minimized windows, invalid window dimensions, monitor topology changes, current-monitor changes, window movement, and resizing.
- Disabled display conditions cannot start or extend recovery. Monitor loss cannot bypass its disabled option through monitor-change detection. Ordinary movement and resizing remain excluded by default.
- Added separate options for rendering during area transitions, rendering while logged out, and periodic frames in frozen-frame and background modes. Legacy black-screen mode does not gain periodic frames.
- Background recovery pulses now temporarily allow rendering without changing saved mode settings. Disabling an active exception cancels its pause or pulse, and pending pulse timers cannot undo manual restore or Stop actions.
- Made automatic changes to AutoRetainer's rendering setting opt-in.
- Timing fields appear only when their corresponding recovery feature is enabled. Updated mode labels and diagnostics to show the selected exceptions.
- Preserved ordinary background focus/minimize eligibility, manual restore commands, All Off, Stop, and unload cleanup.
